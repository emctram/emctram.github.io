# Emily and Ruairidh wedding website

Upload the contents of this folder to a GitHub repository and publish the `main` branch from the repository root using GitHub Pages.

## Before publishing

- Confirm the shared password in `index.html` (`const previewPassword=`).
- Confirm both mobile numbers.
- Remember that the password gate is a casual deterrent, not secure authentication; the repository and page source are public on free GitHub Pages.
- Test the Tally form and map on phone and desktop.
